# 디스코드 봇 웹 콘솔 — 진행상황

마지막 업데이트: 2026-11-24

## 구조 (폴링 방식)
호스팅(WeirdHost)이 외부 접속을 막아서(26130 포트 ERR_CONNECTION_TIMED_OUT), 봇이 바깥으로 5초마다 Cloudflare에 작업을 가져가는 방식을 쓴다.

```
브라우저 -> Cloudflare Pages(_worker.js, D1에 작업 저장) <- 봇(webapi.js)이 5초마다 확인 -> 실행 -> 결과를 D1에 저장 -> 브라우저에 표시
```

- 주소: `https://console-2qd.pages.dev` (패널: `/` `/shop` `/music` `/mod`)
- GitHub 저장소 `console`의 `cf-test-upload` 폴더 = Cloudflare Pages 빌드 출력 디렉터리
  - 파일: `_worker.js`, `index.html`
- 로그인: 디스코드 OAuth2(identify). 권한(관리자 여부, 서버 멤버 여부)은 **봇이 직접 재검증**한다.

## 파일 목록
| 파일 | 위치 | 설명 |
|---|---|---|
| `_worker.js` | GitHub `cf-test-upload/` | 로그인, 작업 큐, 패널 주소 라우팅 (`/shop` `/music` `/mod` `/cmd`) |
| `index.html` | GitHub `cf-test-upload/` | 화면 전체 (홈/상점/음악/관리) |
| `webapi.js` | WeirdHost, `index.js` 옆 | 봇 쪽 폴링과 작업 처리 |
| `index.js` | WeirdHost | `require('./webapi')({ client, queues, C, db })` 한 줄이 들어간 버전 |

- 로고: `logo/` 폴더 (`logo-mark.svg` 아이콘, `logo-full.svg` 가로형, PNG 포함). 상단 바와 탭 아이콘(favicon)에 적용됨 (index.html 안에 인라인)

## 설정값
**Cloudflare (Settings > Variables and secrets / Bindings)**
- `BOT_SYNC_SECRET` (Secret) = 봇 `.env`의 `WEB_SYNC_SECRET`과 같은 값
- `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`(Secret), `DISCORD_REDIRECT_URI` = `https://console-2qd.pages.dev/auth/callback`
- 바인딩 `DB` = D1 데이터베이스 (`console-db`)
- 개발자 포털 > OAuth2 > Redirects에 위 redirect 주소 등록

**봇 `.env`**
- `WEB_SYNC_URL=https://console-2qd.pages.dev`
- `WEB_SYNC_SECRET=...` (Cloudflare와 같은 값)
- `WEB_GUILD_ID=서버ID`
- (선택) `WEB_TEXT_CHANNEL_ID` — 웹에서 재생할 때 봇 안내 메시지가 올라갈 채널, `WEB_POLL_SEC` — 확인 주기(기본 5초)

**D1 테이블** (`jobs`, `sessions`)
```sql
CREATE TABLE IF NOT EXISTS jobs (id TEXT PRIMARY KEY, type TEXT NOT NULL, data TEXT, actor TEXT, status TEXT NOT NULL, result TEXT, created INTEGER NOT NULL);
-- 예전에 jobs를 만들었다면: ALTER TABLE jobs ADD COLUMN actor TEXT;
CREATE TABLE IF NOT EXISTS sessions (token TEXT PRIMARY KEY, discord_id TEXT NOT NULL, username TEXT, created INTEGER NOT NULL);
```

## 기능
- 홈: 서버 현황 카드(멤버, 채널, 역할, 응답 속도, 가동 시간, 재생 중 서버) 숫자 카운트 애니메이션
- 상점(`/shop`): 발로란트 상점/장식상점/번들/야시장 탭(표시선 이동), 계정 전환, 새로고침, 카드를 누르면 상세 시트
  - 본인이 디스코드 `/vlogin`(QR)으로 등록한 계정만 조회, 토큰은 웹으로 보내지 않음
- 상점 QR 로그인: `/shop`의 '계정 추가 (QR)' 버튼 -> 봇이 QR 생성 -> Riot Mobile 앱으로 스캔(다른 기기) -> 승인되면 계정 등록. 승인 대기는 봇이 백그라운드로 처리(작업 큐를 막지 않음)
- 음악(`/music`): 재생 상태와 진행 막대, 스킵/일시정지/재개/정지, 대기열 목록, 반복 모드, 음량 슬라이더, 채널에서 내보내기, 재생하기
- 관리(`/mod`, 관리자만): 멤버 검색, 경고 기록 확인/초기화, 경고/뮤트/뮤트 해제/추방/차단/차단 해제, 뮤트 기간 버튼, 차단/추방 전 확인 시트
- 명령어(`/cmd`): index.js 에 등록된 모든 slash 명령어를 폼으로 자동 생성해 실행 (관리자 명령어는 관리자에게만 보임, 위험 명령은 확인 시트). Ctrl+K 로 어디서나 패널/명령어 검색
  - 명령어는 등록된 파일별(economy.js, index.js, invites.js, musicpanel.js, scrim.js, tickets.js, valstats.js)로 묶여 표시되고 파일 칩으로 필터 가능 (`index.js`의 `CMD_SRC`/`markSrc` 로 출처 기록)
  - '최근 실행 결과': 최근 1시간 내 실행 기록과 결과(이미지 포함)를 다시 열어볼 수 있음 (`/api/history`)
  - 제외: `vlogin`(웹 QR 로그인이 따로 있음), `help` / 첨부파일 옵션은 웹에서 불가 / 채널이 필요한 명령(purge, slowmode, lock, unlock)은 실행 채널 선택
- 공통: 이모지 전부 제거(봇이 보내는 문구도 화면에서 제거), 토스트 알림, 바텀시트, 스프링 버튼, 스켈레톤 로딩, 스크롤 등장 효과, 모바일 대응, 동작 줄이기 설정 존중

## 보안 메모
- 작업 등록은 로그인 세션 필요, 결과는 본인이 만든 작업만 조회, 1분에 20건 제한
- 관리 작업은 봇이 서버 멤버의 Administrator 권한을 다시 확인
- OAuth `state` 확인, 세션 7일 만료, 로그인 후 돌아갈 주소는 허용 목록(`/shop`, `/music`, `/mod`)만

## 알려진 한계
- 봇이 작업을 하나씩 처리해서, 상점 첫 조회(스킨 목록 다운로드, 10~30초)가 길면 같은 시간대의 음악 요청이 잠깐 밀릴 수 있음
- 발로란트 로그인 토큰은 약 1시간 뒤 만료 (QR 로그인은 쿠키가 없어 자동 갱신 불가) -> 디스코드에서 `/vlogin` 다시
- 일시정지 상태의 진행 막대는 정지된 시점 기준으로 근사
- 명령어 결과의 이미지 첨부(files)는 웹에 표시되지 않음 (임베드 이미지 URL만 표시)
- 실제 서버/로그인 환경에서의 최종 동작은 아직 검증하지 못함 (가짜 응답으로 화면/문법만 검사)

## 배포 순서 (바뀐 파일만)
1. GitHub `cf-test-upload/`에 `_worker.js`, `index.html` 덮어쓰기 -> Cloudflare 자동 배포
2. WeirdHost에 `webapi.js`, `index.js` 덮어쓰기 -> 봇 재시작 -> 로그에 `[webapi] 웹 콘솔 연결됨`
3. 사이트에서 Discord 로그인 확인
